# Mode · dashboard

What needs attention today. **Derived from the records every time**, never carried forward.

## Build it in this order

1. **Deadlines inside a week where nothing has been sent.** Nothing else is more urgent.
2. **Ready and unsent.** Each with a send-by date. If it has none, it needs one now.
3. **Named contacts never used.** A route that exists and has never been tried.
4. **Applied and silent past their stated timeline.** One polite follow-up each.
5. **Anything awaiting a decision from you**, stated as the actual question.
6. **Anything whose liveness has not been checked in a fortnight** and that you still want.

## Rules

- **Derive it, do not remember it.** [G-13](../lessons/G-13-status-comes-from-the-record.md)
- **Short.** A list of thirty items is a list nobody reads. If everything is urgent, sort by
  deadline and show the first five.
- **Say what is quiet.** "Nothing needs you today" is a valid and useful answer.
