# modes/

A mode is a task playbook. You name one, the agent follows it. They are plain markdown on
purpose, so you can read what the agent is about to do and change it before it does.

> Every example in this kit is invented. See the disclaimer in the [README](../README.md).

| Mode | Use it when |
|---|---|
| [`_profile.md`](_profile.md) | **Start here.** A blank form. Nothing else works until it is filled in. |
| [`scan.md`](scan.md) | Finding roles |
| [`evaluate.md`](evaluate.md) | Deciding whether a role is worth applying to |
| [`cover-letter.md`](cover-letter.md) | Writing the application |
| [`outreach.md`](outreach.md) | Writing to a person, and following up |
| [`interview-prep.md`](interview-prep.md) | Preparing for a conversation |
| [`debrief.md`](debrief.md) | **After anything happens.** An interview, a rejection, a reply, a silence |
| [`critic.md`](critic.md) | Before anything leaves your hands |
| [`tracker.md`](tracker.md) | Keeping the record straight |
| [`dashboard.md`](dashboard.md) | Deciding what to do today |
| [`lessons.md`](lessons.md) | Turning what you learned into a rule |

## The loop these form

    scan -> evaluate -> cover-letter -> critic -> YOU SEND -> debrief -> lessons
                                                                  |
                                                        tracker <-+-> dashboard

**`critic` sits before every send and `debrief` after every outcome.** Those two are what make
the kit compound rather than just automate.
