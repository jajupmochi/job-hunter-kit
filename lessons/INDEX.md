# Lessons

Fifteen rules, each written after getting it wrong. **Every one is stated so it holds outside
any single profession**, because a rule you have to translate before using is a rule you will
not use.

> Every example in this kit is invented. See the disclaimer in the [README](../README.md).

## Writing the application

| | Rule |
|---|---|
| [G-01](G-01-anchor-it-in-them.md) | Paragraph one names something only this employer would recognise. Swap their name out; if it still reads, it is a template. |
| [G-02](G-02-no-boilerplate-opening.md) | Do not spend the first sentence announcing that you are applying. |
| [G-03](G-03-show-do-not-assert.md) | Replace every self-assessment with a fact a stranger could check. |
| [G-04](G-04-three-part-body-conversation-close.md) | Them, you against their list, the shared problem. Close by asking for a conversation. |
| [G-05](G-05-name-the-gap.md) | Name one real gap and say what you would do about it. Never apologise. |
| [G-06](G-06-match-evidence-to-the-title.md) | Read whether the title screens for delivery or depth, and lead with that. |

## Truth

| | Rule |
|---|---|
| [G-07](G-07-every-claim-has-a-source.md) | Every claim traces to a source or is marked unknown. Numbers re-checked, never remembered. |
| [G-08](G-08-change-only-what-the-rule-requires.md) | Revising? Change what was asked for and leave the rest of their voice alone. |
| [G-09](G-09-measure-a-rule-change-first.md) | Measure a rule change against real data before applying it. The obvious fix is often net negative. |
| [G-15](G-15-write-as-if-they-will-read-it.md) | Write every note as if the people in it will read it. Record the decision, not the verdict. |

## Verifying the world

| | Rule |
|---|---|
| [G-10](G-10-a-positive-test-before-any-claim.md) | A positive test before any claim about the world. Absence of a negative is not a positive. |
| [G-11](G-11-a-negative-is-a-fact-about-your-method.md) | A negative result is a fact about your method. Run a control against something you know is there. |
| [G-12](G-12-read-the-eligibility-clause-first.md) | A working link is not proof you may apply. Read the eligibility clause first. |

## Running the process

| | Rule |
|---|---|
| [G-13](G-13-status-comes-from-the-record.md) | Status comes from the record, never from your last summary. Write decisions down the same day. |
| [G-14](G-14-look-before-you-write.md) | Look before you write. Verify from the artifact. Match on the identifier, not the title. |
