# G-10 · A positive test before any statement about the world

**"It works", "it is open", "it is done" are claims about the world. Each needs a test that
would have failed if the claim were false.**

## The three that matter in a job search

**A posting is open only if you fetched it today.** Not "the search engine listed it", not
"the link works". Aggregators keep dead postings for weeks. **Go to the employer's own board.**

**A page rendering is not a posting accepting.** An advert can be live while the application
form is closed, the deadline passed, or the requisition withdrawn. Those are different facts.

**An acknowledgement is not a response.** An automated receipt from an applicant tracking
system is a machine confirming receipt. Reading it as interest is how people wait three weeks
for a conversation that was never happening.

## The general form

Before saying something is true, ask: **what did I actually observe, and would I have observed
something different if it were false?** If the answer to the second is no, you have not tested
anything.

## Absence is not evidence

"No rejection yet" is not "still under consideration". "The link still works" is not "still
hiring". "They viewed my profile" is not "they are interested". **The absence of a negative
signal is not a positive signal**, and building a plan on one costs weeks.
